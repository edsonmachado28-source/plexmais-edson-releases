# plexmais-edson-releases
PlexMais reúne seu servidor Plex e suas listas IPTV em uma interface feita para controle remoto na Android TV. Assista filmes, séries e canais ao vivo com guia de programação, favoritos e histórico que retoma de onde você parou. Requer Android TV 9+, um servidor Plex e/ou uma lista IPTV.
